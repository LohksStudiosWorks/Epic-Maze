# Epic Maze

This is the epic game made by Lohk in early graduation days. This was remade two times, once using Allegro 5, and now with SDL3.

## How to play

Download the latest release over [GameJolt](https://gamejolt.com/games/epic_maze_revamped/392757).

Controls (Desktop):

- `W`, `A`, `S`, `D`: controls up, left, down, right
- `Enter`: Select
- `Escape`: Go back / Pause 
- Mouse controls:  
  - `Click`: Select
  - `Drag and move`: Joystick-like movement (in game)

Android:
- `Touch`: controls, movement with touch and drag
- `Back button / gesture`: Go back / Pause
